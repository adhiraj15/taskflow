# TaskFlow

TaskFlow is a simple Python Flask application used to practise DevOps tools.

## Tools
- Linux
- Git and GitHub
- Docker
- Jenkins and CI/CD
- Kubernetes with Minikube

## Kubernetes
The `kubernetes/` folder contains configuration files for:
- Deployment and Service
- ConfigMap and Secret example
- Persistent storage (PVC)
- Autoscaling (HPA)

## Notes
- The application runs on port 5000.
- The Kubernetes setup uses Minikube.
- Never upload real passwords or tokens to GitHub.
- Jenkins webhook and HTTPS webhook testing were practised.
